## About me

I am a **Full-Stack Developer** with a degree in **Systems Analysis and Development from Fatec Itapetininga**. Since October 2025, I have worked as a **Junior Front-End Developer at Code and Soul** on projects for TIM.

In my day-to-day work, I use **Drupal and Acquia Site Studio** to build pages from Figma layouts, configure components and dynamic content, and adapt interfaces with **HTML, CSS, JavaScript, and jQuery**. I work with client requests, delivery deadlines, and the review of offers and FAQs in a team that uses agile methodologies and **Azure Boards**. I also develop data-mapping automations and manage bulk updates using **Drupal Feeds**.

**I built a Figma plugin from scratch, integrated with Drupal through an API**, and was primarily responsible for its technical design and initial development. I collaborated on integration testing with the backend and led the migration of the interface to **React** to make the tool easier to maintain and extend.

In personal, academic, and freelance projects, I use **Next.js, TypeScript, Strapi, Supabase/PostgreSQL, and Firebase**, working on interfaces, API routes, authentication, content modeling, and data persistence. I use **Claude and Codex** to support code analysis, implementation, refactoring, and documentation, while reviewing and validating the results.
